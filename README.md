# HT_Studio

Monorepo chứa các công cụ UXP cho Adobe Premiere Pro.

- `HT_Automation`: panel tự động hóa media, audio, subtitle và FFmpeg Bridge.
- `HT_BinBuilder`: panel xây dựng và sắp xếp bin trong Premiere Pro.

Mỗi dự án có hướng dẫn, manifest, mã nguồn và bộ cài riêng trong thư mục tương ứng.
